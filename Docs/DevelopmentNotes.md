# Gridbound：第一人称实时格子战斗

项目：`Gridbound.uproject`；引擎：`<UE_ENGINE_ROOT>`（UE 5.8.2）。草地、河流、砂石、人物和技能均使用原创程序化低多边形美术。

## 操作

| 输入 | 效果 |
|---|---|
| WASD | 相机相对八方向格子移动；W+A、W+D、S+A、S+D 可斜走 |
| 空格 | 跳跃，支持移动中和墙顶起跳；空中不能再次起跳 |
| 鼠标 | 第一人称观察，上下可转 85 度；向脚下看可升墙托举自己 |
| Q / E / R | 选择火球术 / 土墙术 / 降雨术，不立即施放 |
| 左键 | 施放当前技能，施放后保留选择 |
| 右键 | 土墙预览在 1×5 与 5×1 之间旋转 |
| F5 | 重置血量、敌人、墙体、火球、燃烧、泥地、雨效、冷却及高度 |
| Shift + F1 / Esc | 编辑器中释放鼠标 / 结束 Play |

旧 Bolt、Burst 和数字 1 施法已经移除。

## 数值与规则

- 玩家和敌方战士均为 100 HP。开局 3 名战士；全部死亡后补充 1 名战士，之后每次清场重复补充。
- 玩家出生点为格坐标 (3,10)，蓝色标记；敌方补充出生点为 (6,11)，红色标记。格坐标从 0 起算，可通过 `PlayerSpawnCell` / `EnemySpawnCell` 配置。出生点被土墙、火焰或人物占据时使用最近的安全格；没有安全格时等待后重试。
- 玩家 0 HP 后停止移动和施法，2 秒后在重生点恢复 100 HP，清空移动、跳跃与技能冷却。重生保留敌人、土墙和地形效果；F5 才会重置整个场地。
- 战士主动寻路追击，每格 0.45 秒，泥地速度降为 50%。优先绕过土墙，没有可行绕路时劈砍挡路土柱；移动预留目标格，避免人物相互穿过。
- 劈砍：冷却 1 秒，20 人物伤害，10 拆毁值；近战距离约一格，高度差不超过 100 厘米才可命中人物，遮挡会阻止攻击。劈砍一次命中一个目标，两类数值独立。新战士和玩家重生后至少等待 1 秒才可攻击。
- 角色伤害与物品拆毁值完全分开：角色只扣 HP；土柱只扣耐久。
- 火球：50 角色伤害、50 拆毁值，首个碰撞即停止，不穿透、不溅射；速度 1800 厘米/秒、距离 6 格、冷却 0.6 秒。使用球体扫掠检测。
- 土墙：1×5 或 5×1 格、高 3 格。每根 1×1 格土柱独立拥有 100 耐久和 60 秒寿命；两发火球拆掉命中的一根，邻柱不受影响。施法范围为玩家周围 10 格（曼哈顿距离），冷却 2 秒。
- 土墙可以在自己或敌人脚下生成，约 0.35 秒升起并托举人物。角色可沿墙顶走动或走下墙顶；支撑土柱被拆掉或到期后按重力下落，当前不计算坠落伤害。地面角色不能直接跨上完整高墙。
- 正在移动的角色若与新墙相交，会先落定到最近的物理格再托举，防止穿入墙内。土墙逐格跳过越界、超过 10 格、被土柱或物体占据、视线受阻的位置；例如一格被挡就只生成其余四格。所有位置都受阻才施法失败。人物不算障碍，仍会被托举。预览绿色格会生成，红色格会跳过。
- 火球命中草地会点燃命中格；河流和砂石不可燃。草地燃烧 10 秒，对接触地面的玩家和敌人造成每秒 10 HP 伤害。重复命中刷新时间，不叠加伤害，不自动蔓延。
- 站在墙顶或正在空中的人物不会受到地面火焰伤害。自然熄灭后留下焦土地面，60 秒后恢复草地；恢复前可以再次点燃并重新计时。
- 降雨术：R 选择后左键施放，目标中心射程 10 格，冷却 4 秒（默认参数）。范围为半径 4 格的圆，以格子中心判断 `dx²+dy²≤16`，完整范围共 49 格；边缘裁剪到地图内。雨效持续 3 秒，地形效果在施放时立即应用。
- 降雨熄灭覆盖范围内的燃烧草地，把燃烧/焦黑草地和砂石变为泥地；健康草地和河流不变。重复降雨刷新泥地恢复计时，不叠加减速。
- 泥地使接触地面的角色移动速度降为 50%：玩家从泥格出发的一步耗时由 0.3 秒变为 0.6 秒；墙顶/空中不受减速。减速实时影响步进进度，干燥后恢复正常，敌方战士同样受泥地减速。
- 泥地 60 秒后恢复该格原本的草地或砂石，包括原美术；泥地湿润期间不能被火球点燃。F5 可立即重置全部地形。
- 每格 150 厘米；土墙高度 450 厘米。第一人称眼高 130 厘米、FOV 90 度，镜头随托举及下落移动。移动过程逻辑格在抵达后更新。
- 行走方向将合成后的 WASD 输入按相机水平朝向旋转，取最近的八个网格方向之一（45 度间隔）；相反按键抵消。正在执行的一步不会因转动镜头而弯曲，下一步使用新的方向。
- 从静止单键起步时保留 60 毫秒组合键窗口，合并分帧到达的 W+D 等按键，避免先直走再斜走。同帧组合立即起步；单键短按在松开时立即确认一格；持续行走与途中换向不重复等待。
- 直走一格约 0.3 秒，斜走一格约 0.424 秒，保证实际移动速度相同；泥地分别约 0.6 秒和 0.849 秒。斜走会检查两个侧邻格，避免穿过墙角。
- 跳跃高度 145 厘米（约 0.97 格），0.41 秒到达最高点，平地滞空约 0.82 秒。初速度与跳跃重力由高度及上升时间计算。落地后可以再次起跳；支持墙顶起跳和落回墙顶，支撑柱消失后继续落到地面。普通下落重力为 980 厘米/秒²，当前无坠落伤害。
- 跳跃不阻止施法，镜头随高度移动。离地后不受脚下泥地减速与地面火焰伤害。技能射程仍沿用原来的曼哈顿距离，降雨范围仍为格子圆形。

## 美术与反馈

- 火球：分面亮色核心、锥形焰尾、碎火星。
- 土柱：削角轮廓、六层土岩分面、层理；受损后出现扩大的分叉裂纹、暗色缺口和碎石，完整/受损/重损阶段可区分。
- 燃烧草地：焦黑分面地表、炭化草叶、脉动多边形火苗和火星；熄灭后留下焦土。
- 土柱拆毁或到期产生短暂碎石残留。准星瞄准土柱显示该根耐久和剩余时间。
- 降雨：灰蓝分面云团、循环下落的棱形雨滴与地面水花。泥地：深棕三角分面、蓝灰水洼、积水高光及湿石/炭化草叶。
- 敌方战士：红色低多边形人物、银色剑及挥砍动作，头顶显示 Warrior 与剩余 HP；敌我出生点使用红、蓝地面标记。

## 开发与运行

- `Scripts/OpenEditor.ps1`：打开编辑器，地图 `Content/Maps/GridArena`，点击 Play。
- `Scripts/Play.ps1`：独立游戏窗口。
- `Scripts/Build.ps1`：编译并创建材质、地图；关闭该项目编辑器后执行。
- 地形及技能美术在运行时生成。新增形状沿用 `M_FacetedTile` 顶点色材质，没有第三方素材依赖。

源码：`GridGame.h/.cpp`（输入、镜头、火球、HUD），`GridEnvironment.cpp`（耐久、寿命、托举、灼烧），`GridArt.cpp`（低多边形美术）。自动化测试：`GridTests.cpp`、`GridCombatTests.cpp`、`GridEnvironmentTests.cpp`。

`GridRain.cpp` 实现降雨、泥地计时和速度倍率、土墙逐格裁剪；`GridRainTests.cpp` 验证圆形范围、灭火、恢复、减速及部分土墙生成。

`GridMovement.cpp` 实现跳跃入口、八方向步进与斜向夹角阻挡；`GridMovementTests.cpp` 验证方向合成、相机跟随、速度、泥地、起跳/落地、墙顶及重置。

`GridWarrior.cpp` 实现战士寻路、劈砍、敌我出生与重生；`GridWarriorTests.cpp` 验证战斗和重生回归。

`-GridboundCombatShowcase -GridboundScreenshot` 是开发版可选的美术验证场景参数，普通启动不会生成展示场景。

降雨展示场景使用 `-GridboundRainShowcase -GridboundScreenshot`。正常试玩请使用上一级目录的 `启动最新版Gridbound.cmd`；编辑器使用 `编辑最新版Gridbound.cmd`。

HUD 暂用英文；土墙预览仍使用开发调试绘制。尚未完成独立 Windows 打包或人工键鼠手感验收。
