# 晶核归途 · 单地图关卡

## 当前状态

v0.3.0 已完成 Unreal 编译及 Windows 打包，8 项自动化测试全部通过。已检查独立打包版的中文字体和开局画面，并修复字体初始化崩溃、血条覆盖说明文字和营地标记遮挡镜头。人工完整通关与平衡性体验尚未进行。

## 目标与空间

一张 32×32 格、每格 150 cm 的连续地图，外框约 48×48 米；总格数由 400 增至 1024。取消分段门、三个技能信标、逐区域清敌及传送检查点。

玩家从西侧绿色营地出发，渡河到东侧遗迹，靠近金色晶核按 F 拾取，再返回营地按 F 撤离。守卫未被消灭也可完成目标。死亡回营地，携带中的晶核掉在死亡地点，可以回收；F5 重置整局。

- **营地**：(2,10)，安全阅读区，绿色地标。
- **草地渡口**：河道上 y=9～11 的三格宽通路。草地可燃，封锁敌人也可能封锁自己。
- **砂石渡口**：y=20～22 的三格宽通路。位置较远，降雨可制造泥地，换取撤退时间。
- **破碎石脊**：x=20，多处缺口形成绕行路线，切断视线；短墙不再把地图分成重复房间。
- **遗迹**：x=26～29、y=14～18，高 300 cm。西侧三格宽阶梯每级升高 60 cm，玩家可跳跃上台；土墙可在侧面抬升玩家形成捷径。
- **晶核**：(27,16)，金色高光柱在地面上提供方向；拾取后引导光柱改指营地。

## 技能选择的代价

1. **火球封路**：用燃烧草地迫使追兵绕路；守卫不会自愿长期站在火中。火球也能直接造成伤害或拆掉土柱。
2. **降雨控场**：在砂石路上提前造泥减速追兵；也可以扑灭自己退路上的火。泥地同样减速玩家，必须规划站位。
3. **土墙分割**：可封住三格宽渡口，将守卫分隔在另一侧，也能抬升自己进入遗迹。守卫会比较绕行和拆墙的成本；一根土柱被打坏就会产生缺口。
4. **高地与回程**：土墙登高速度快，阶梯不消耗技能冷却；晶核拿到后需要原路或绕另一处渡口撤退，去程的泥地和土墙仍可能改变回程。

不设置“必须施放某个技能”的钥匙检查。解法来自路线、视线、敌人位置、技能冷却和临时地形，而非重复击杀后按键开门。

## 守卫

十名固定守卫分散于渡口、石脊和遗迹。保留 100 血量、劈砍 20 伤害、10 拆毁值及 1 秒冷却。

- 近距离视线发现玩家；附近同伴接收警戒位置。
- 失去视线后追到最后已知位置，警戒消退后寻路返回巡逻区域，不隔墙持续读取玩家位置。
- 拾取晶核警报只影响附近守卫，远处巡逻不全图锁定玩家。
- 根据泥地、燃烧和拆墙耗时选择路径，优先离开脚下火焰。
- 劈砍有 0.45 秒预备动作并锁定目标格，玩家可以离格躲避。
- 可沿遗迹阶梯追击，不能直接跨上完整土墙。

## 中文与界面

仅显示中文玩法介绍、当前技能（位于玩法介绍内）及生命值。删除英文标题、版本文字、技能数值面板、小地图、统计、敌人名称和土柱耐久倒计时。敌人只留血条，并检查视线，避免隔墙显示。

保留小瞄准点、施法范围预览和近战落点提示，作为操作反馈。使用 Droid Sans Fallback 中文字体；字体及 Apache 2.0 许可一起加入打包目录。
